# Aamna Sayyed — Portfolio

A responsive portfolio recreated from the screenshots you provided. It uses plain HTML, CSS, and JavaScript.

## Files
- `index.html` — page content and sections
- `style.css` — layout, colors, responsive styling
- `script.js` — mobile navigation and project-link setup

## Preview locally
1. Extract the ZIP.
2. Open the folder in VS Code.
3. Open `index.html` in your browser (or use the Live Server extension).

## Before publishing
1. In `index.html`, replace `your-email@example.com` with your email address.
2. In `script.js`, add the live URLs for each of your four projects.
3. Check all text and skill levels and adjust anything that doesn't match your actual experience.

## Publish free with GitHub Pages
1. Sign in to GitHub and create a **public** repository, for example `aamna-portfolio`.
2. Upload `index.html`, `style.css`, `script.js`, and `README.md` to the repository root.
3. Open the repository's **Settings → Pages**.
4. Under the build/deployment source, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then save.
6. Wait for GitHub Pages to publish and open the URL shown on that settings page.

This version is a static website and does not require a custom domain. Google Fonts requires an internet connection; system fallback fonts are included.
